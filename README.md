# ToneTester - 四選一音高答題遊戲 (C3 ~ C5 男聲領域)

專為聽力與音感訓練打造的網頁版音高測驗遊戲。

---

## 🌟 核心特色與實作規格

1. **題目範圍：C3 ~ C5（男生音高核心領域）**
   - 涵蓋 MIDI 48 (C3) 至 MIDI 72 (C5) 共 25 個半音。
   - **🌱 純白鍵自然音模式（可隨時一鍵開關）**：關閉所有 ♯ / ♭ 升降半音，題目與選項僅出現白鍵（Do, Re, Mi, Fa, Sol, La, Si，共 15 個音符），消除黑鍵干擾，最適合新手入門！
   - 每題隨機選取一個音高作為題目，自動防範連續重複出題。

2. **多難度混淆項生成演算法**
   - **寬音距拉開（新手友善 ⭐ 預設）**：四個選項在 C3~C5 間平均拉開（相差 4~7 個半音，高低音區分明），不再有容易搞混的相鄰音，聽出高低立刻選對！
   - **智能平衡混淆（⭐⭐）**：近鄰半音（±1, ±2）、和聲音程（三/四/五度）與八度陷阱組合。
   - **微音階極限（⭐⭐⭐）**：極限挑戰，選項全部落在 ±1~±4 半音之內。
   - **和聲音程陷阱**：三度、四度、五度與八度泛音列陷阱。
   - 採用 Web Audio API 物理聲學多泛音疊加合成（包含弦不和諧性 Inharmonicity、同音多弦微失諧 Unison Detuning、8ms 琴槌敲擊瞬態雜訊與自然指數衰減）。
   - 音色純淨自然，支援即時快取，零網路延遲。

3. **「再播一次」按鈕防呆機制**
   - 題目播放期間（約 1 秒），按鈕自動禁用並顯示倒數進度，防止誤觸。
   - 播放完畢後自動解鎖，恢復為「🔊 再播一次」。
   - **答案揭曉後依然能正常運作**：答題後可無限次重播題目音，加強聲音與音名的聽覺連結。

4. **智能混淆項生成演算法（非隨機盲選）**
   - 每一題必定有 1 個正確答案，隨機分配在 A、B、C、D 其中一個位置。
   - 其餘 3 個干擾項由專用演算法生成，避免產生離譜且一眼看穿的選項：
     - **鄰近半音陷阱（±1、±2 個半音）**：製造人耳最容易混淆的微小音高偏差。
     - **和聲音程陷阱（三度、四度、五度）**：利用泛音列共鳴常引發的調性錯覺。
     - **八度音陷阱（±12 個半音）**：音名與音色相同但音區不同的典型聽覺盲區。
     - **音域平衡控制**：動態調整正負偏移，避免正確答案永遠落在最高音或最低音。

5. **清晰雙重標記與自主掌控步調**
   - 點選選項後立即鎖定按鈕，防止重複作答。
   - 選項卡片以雙重視覺標記：
     - 使用者選擇的選項：標示 **「你的選擇」**（選對為翠綠、選錯為玫紅）。
     - 正確答案的選項：標示 **「✓ 正確答案」**（亮綠色高光發光邊框）。
   - 出現「下一題」按鈕，**絕不自動跳題**，讓使用者自主掌控複習與對照時間。

6. **互動式鋼琴鍵盤視覺化 (C3 ~ C5)**
   - 頁面下方配備完整 25 鍵鍵盤，答題後在鍵盤上即時標記正確音與你的選擇，並顯示兩音差距的半音數與音程名稱。
   - 點擊鍵盤上任何琴鍵皆可發聲試聽，方便即時比對。

7. **鍵盤快速鍵**
   - `A` / `B` / `C` / `D` 或 `1` / `2` / `3` / `4`：選擇對應選項
   - `R`：再播一次
   - `Enter` 或 `Space` 或 `N`：下一題（揭曉答案後）

## 🚀 啟動方式

本專案為純前端單頁應用程式（HTML5 + CSS3 + Vanilla JavaScript），無須安裝任何套件：

### 方式 1：直接雙擊開啟（最快速）
直接以瀏覽器（Chrome、Edge、Safari、Firefox）開啟：
```
file:///Users/severus/ToneTester/index.html
```

### 方式 2：使用本地 HTTP 伺服器
若習慣以 localhost 形式執行，可以在本目錄執行：
```bash
# 使用 Python 內建伺服器
python3 -m http.server 3000

# 接著在瀏覽器打開 http://localhost:3000
```
